## 4. Решение директора

**P1 — discovery, без изменения P0 и без запуска разработки.** Проверить ценность нескольких именованных участков и сохранения контекста между тренировками. Core P0 остаётся прежним: сначала подтвердить рабочую реализацию A–B/N/паузы/countdown/голосовой очереди на APK. Не переносить в roadmap social/teacher/AI-функции по единичным релизам конкурентов.

## 5. Один дешёвый тест

**25 минут, 0 ₽.** Взять одну реальную постановку с тремя сложными местами. Засечь: (а) повторную ручную разметку одного A–B на второй сессии; (б) выбор из трёх заранее подписанных сегментов в бумажном/статическом сценарии. Успех: нужный сегмент запускается за ≤10 секунд, без повторной разметки и минимум на 30% быстрее baseline. Результат — только discovery evidence, не доказательство спроса.  
Тикет-кандидат: **DISC-NAMED-SECTIONS-01**.

## 6. Одно маркетинговое действие

Подготовить, **не публиковать**, черновик 15-секундного storyboard: «Три сложных перехода → три сохранённых участка → завтра продолжил с нужного места». Пока пометить функцию как гипотезу, не как доступную возможность Midnight Dancer.
