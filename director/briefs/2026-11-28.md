## Резюме

Есть **узкая, но реальная конкурентная дельта**: SHOEOUT выпустил iOS 1.9.2 и дорабатывает не «ещё один AI-балл», а надёжность входа и практический путь от записи к разбору. При этом в открытом пуле за сутки не найден повторяющийся пользовательский запрос на AI-разбор, а качество конкурентных AI-обещаний не подтверждено независимыми отзывами.

**Решение: P1 — только discovery; roadmap не менять.** P0 остаётся прежним: подтвердить реальную работу A–B/N/rest/countdown/voice queue на APK. AI-разбор, Watch и новые режимы в разработку не передавать.

## Связки сигнал → продукт

### 1. SHOEOUT 1.9.2

**Рыночный сигнал:** scoring ограничивают видимыми движениями, guide адаптируют к layout  
→ **боль:** автоматическая оценка может судить невидимого/не того танцора и оставлять непонятный балл  
→ **гипотеза:** пользователю полезнее один достоверный следующий шаг, привязанный к короткому фрагменту, чем общий AI-score  
→ **функция-кандидат:** точная подсказка «что исправить» + переход в соответствующий A–B-участок; **без AI на текущем этапе**  
→ **критерий успеха:** пользователь за ≤10 секунд называет следующую отработку и выбирает нужный участок без пересмотра всего ролика; нет подсказки по невидимому движению  
→ **дешёвый тест:** бумажное сравнение форматов A/B ниже  
→ **тикет-кандидат:** `DISC-ACTIONABLE-FEEDBACK-01` — не создан.

### 2. Dance Studio AI 2.4

**Рыночный сигнал:** beat detection + AI-разложение собственного видео до 60 секунд спрятаны за freemium/paywall  
→ **боль:** танцор может найти нужный фрагмент, но не понять состав движения  
→ **гипотеза:** ручная визуальная/текстовая декомпозиция 8-count может ускорить воспроизведение только при достаточной точности  
→ **функция-кандидат:** не разрабатывать; сначала ручной прототип названий движений поверх одного 8-count  
→ **критерий успеха:** незнакомая связка воспроизводится после ≤3 просмотров, а разметка не требует исправлений тренера  
→ **дешёвый тест:** только после подтверждения основного A–B-цикла  
→ **тикет-кандидат:** `WATCH-AI-BREAKDOWN-ACCURACY-01` — не создан.

## Один дешёвый тест

**`DISC-ACTIONABLE-FEEDBACK-01`, 20 минут, 0 ₽, без кода и внешних контактов.**

На одном собственном 8-count подготовить две карточки:

- A: только общий score по timing/posture/power/sharpness;
- B: одна конкретная подсказка + ссылка на 3–5-секундный участок и следующую отработку.

Показать последовательно одному внутреннему пользователю/основателю. **Успех B:** за ≤10 секунд правильно названы упражнение и участок, без полного пересмотра видео. Один кейс проверяет только понятность формата, не спрос и не WTP.

## Одно маркетинговое действие

Подготовить, **не публиковать**, трёхкадровый storyboard `MKT-ACTIONABLE-FEEDBACK-STORYBOARD-01`: «не просто 7/10 → вот проблемные 4 секунды → вот следующая отработка». Не заявлять функцию доступной до проверки продукта.
