# Инструменты и подключения

Проверка: 14.11.2026.

| Возможность | Подтверждённое состояние | Применение |
|---|---|---|
| GitHub | Чтение main подтверждено; итог записи проверить по commit и readback | Контекст и director/ |
| Веб-поиск | Выполнен поиск практик и первоисточников | Публичная разведка |
| Automations | Создание подтверждено; enabled=true; следующий запуск 15.11.2026 09:00 МСК | Ежедневный бриф |
| PostHog | Найден в каталоге, installed=false при проверке; предложен пользователю | Кандидат аналитики/воронок/возврата после подключения |
| Amplitude, Mixpanel | Найдены, installed=false | Альтернативы; одновременно подключать несколько не требуется |
| Figma, Sites | Инструменты доступны в сессии, проект Midnight Dancer не проверен | По отдельной задаче макеты и сайт |
| Аналитика Midnight Dancer | Данные/события не проверены, живые показатели неизвестны | Пока проект измерений |
| Магазины/эквайринг | Подключение не подтверждено | Не считать кабинет или платежи работающими |

PostHog не встроен в приложение этой работой. Даже подключённый плагин не создаёт события в APK: нужен отдельный согласованный инженерный цикл и проверка сбора данных. Сейчас бриф работает по открытым источникам.

Выбор инструмента делать по подтверждённой задаче, доступности для владельца, цене и требуемым данным. Не покупать подписки и не менять разрешения автоматически. Секреты — через штатное подключение, не чат/Git.

Внешние агентные пакеты изучены как источники методик. В этот коммит входят собственные документы director/, не установка глобального пакета и не изменение team/skills/.
