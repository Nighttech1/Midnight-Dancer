# Midnight Dancer

Продукт для хранения танцевальных материалов, создания хореографии и тренировок с голосовыми подсказками. Описание функций — вводные основателя; код и сборка в этом репозитории пока отсутствуют.

## Точки входа

- [Запуск нового чата директора продукта](team/START-DIRECTOR.md).
- [Команда, полномочия и карта подчинения](team/README.md).
- [Исходный продуктовый бриф](project-context/PRODUCT_BRIEF.md).
- [Текущее состояние и следующий шаг](team/STATE.md).
- [Правила делегирования субагентам](team/ORCHESTRATION.md).

Команда и её рабочие методики хранятся в этом репозитории. Они загружаются агентами при старте; наличие файлов не означает, что подключены аналитика, магазины, платежи или фоновый сервер агентов.

Проверка структуры: `python3 team/scripts/validate_team.py`.
