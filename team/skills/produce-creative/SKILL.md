# produce-creative

1. Прочитать бриф кампании: сегмент, одна задача танцора, функция, канал, CTA и критерий результата.
2. Проверить реальные экраны/исходники, брендинг, права на музыку, видео и голос. При отсутствии входов выпускать конкретный сценарий/спецификацию, а не выдавать макет за запись продукта.
3. Подготовить композицию/раскадровку; показать голосовые подсказки без приписывания распознавания движений. Синтетический интерфейс пометить макетом.
4. Выбрать доступный инструмент по задаче. Для точного интерфейса использовать реальные экраны/код; для иллюстраций — подходящую генерацию только в разрешённых пределах. Платные API не запускать автоматически.
5. Для видео проверить длительность, кадрирование, аудио, субтитры и синхронизацию; для статики — размер, читабельность, иерархию. Требования магазина/канала проверить перед экспортом.
6. Открыть итоговый файл/preview, проверить видимый результат, зафиксировать формат и ограничения. Выдать материалы CMO; публикацию оставить отдельным действием.

Выход: бриф, концепт/проект, реальные экспорты при доступных инструментах и доказательство визуальной проверки.
