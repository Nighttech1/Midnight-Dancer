# plan-distribution

1. Прочитать бриф, сегмент и границы проверенных функций. Начать с личной пользы: порядок в материалах и тренировка с подсказками.
2. Сравнить каналы: преподаватели/школы, демонстрации в сообществах, создатели контента, карточки магазинов, рекомендации через обмен, платные кампании. Проверить релевантность выбранному рынку.
3. Составить таблицу канал → аудитория → оффер → материал → действие → способ измерения → затраты → владелец. Не выбирать все каналы одновременно.
4. Предложить минимальный пилот. Пример гипотезы: преподаватель демонстрирует тренировку и приглашает учеников попробовать свою библиотеку. Не обещать встроенную публичную библиотеку или готовые пакеты без подтверждения прав/реализации.
5. Создать карту контента: тема, задача танцора, функция, этап воронки, формат, CTA, источник перехода, дата, статус. Публикацию выделить отдельным действием согласования.
6. Для ASO проверить официальные требования конкретного магазина и реальную платформу. Подготовить метаданные/скриншоты и варианты, не публиковать.
7. Для рекламы запросить проверенное измерение и предел расходов. Без разрешения подготовить только медиаплан.
8. Передать план CFO для оценки и аналитику для измерения через директора; получить проверку перед показом владельцу.

Выход: план канала и готовый пакет пилота; установки, активации, удержание и стоимость разделены.
