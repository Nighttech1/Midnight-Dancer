# Инструменты и доступы

Статус на создание пакета. Новый чат обязан проверить фактическую доступность.

| Возможность | Статус пакета | Проверка / следующий шаг |
|---|---|---|
| GitHub Nighttech1/Midnight-Dancer | Чтение проверено при подготовке; итог записи — в отчёте волны | Прочитать текущую ветку/SHA; для записи проверить результат commit/ref |
| Нативные субагенты | В чате подготовки реально выполнена отдельная проверка team_quality; доступность нового чата неизвестна | Повторно обнаружить инструмент; без него последовательный режим. Доказательство текущего прогона — QA.md в runs/MD-202611-TEAM-001/ |
| Поиск в интернете | Может быть доступен платформе | Проверить конкретным поиском; важные выводы по первоисточникам |
| Код и рабочая сборка | Не обнаружены в исходном снимке | Запросить местоположение; не заявлять аудит приложения |
| Продуктовая аналитика | Не подключена | Определить платформу/события, разрешения, провести проверку |
| Магазины приложений | Не подключены, платформы неизвестны | Выбрать актуальные магазины и доступы после уточнения |
| Платежи/расходы | Данные не предоставлены | Получить разрешённые агрегаты и период; без личных данных |
| Рекламные кабинеты/CRM/рассылки | Не подключены | Сначала спецификация и пределы разрешений |
| Рендер/генерация креативов | Не установлены этой поставкой | Проверить инструменты, исходники и стоимость перед использованием |
| LangGraph / smolagents / агентный сервер | Не установлены | Возможный отдельный проект после проверки процесса; не обязательны для нативного делегирования |

Каждую новую интеграцию описывать: владелец, данные, минимальные права, способ безопасного хранения доступа, read-only проверка, стоимость, лог, лимиты, повтор/остановка. Публикация и реальные отправки не служат тестом без разрешения.
