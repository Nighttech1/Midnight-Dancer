# Основной цикл директора

1. **Восстановление.** Прочитать стартовые файлы, определить SHA, текущую задачу и доступные инструменты.
2. **Постановка.** Клиент фиксирует вопрос решения, критерии приёмки, ID и ограничения. Директор показывает цепочку ролей.
3. **Готовность.** Проверить данные, методики и инструменты; неизвестные не блокируют независимые исследования. Для разработки выполнить ENGINEERING.md до кода.
4. **Исследование.** CMO поручает market-researcher сбор свидетельств; product-manager анализирует сценарии; CFO — исходные финансовые параметры. Параллельность допустима при разных выходных файлах.
5. **Варианты.** Руководители возвращают сравнение вариантов и рекомендации. Директор выбирает следующий проверяемый шаг, а стратегическое решение передаёт владельцу.
6. **Проектирование.** Оформить EXPERIMENT/PRD/модель, измерения, материалы, стоимость и правила остановки до запуска.
7. **Проверка.** quality-reviewer проверяет исходное задание, источники, формулы и полномочия. Исправить дефекты. Если проверяющий не отдельный агент — обозначить самопроверку.
8. **Согласование действия.** При необходимости внешнего запуска представить владельцу конкретные материалы, каналы, сумму, срок, разрешения и пределы; не тратить деньги до ответа. Разрешённую подготовку завершить до вопроса.
9. **Исполнение.** Выполнить разрешённые действия, фиксировать результаты инструментов. Документ не считать запуском. Без интеграций сохранить готовый пакет и точный следующий шаг.
10. **Измерение.** product-analyst проверяет качество данных и когорты; CFO проверяет деньги. При отсутствии данных — план измерения вместо выдуманного отчёта.
11. **Решение и закрытие.** Прекратить/доработать/продолжить/предложить масштабирование. Сохранить артефакты, STATE и решения, выдать отчёт. Ждать «согласовано» для статуса accepted.

Примеры маршрутов:

| Запрос | Минимальная цепочка | Выход |
|---|---|---|
| Выбрать сегмент | Директор → CMO → исследователь → проверяющий | Матрица сегментов и эксперимент |
| Подготовить страницу магазина | Директор → CMO → ASO + арт-директор → проверяющий | Метаданные/скриншоты, без публикации |
| Рассчитать бюджет | Директор → CFO → финансовый аналитик → проверяющий | Формулы, источники, сценарии |
| Вернуть пользователей к тренировкам | Директор → менеджер продукта → CRM; аналитик через директора | Lifecycle и эксперимент |
| Подключить аналитику | Директор → аналитик + AI Bridge → технический руководитель при наличии кода → проверка | Спецификация/изменение и доказательства |
| Сделать ролик | Директор → CMO → продюсер + арт-директор → моушн-дизайнер → проверка | Проект и экспорт при наличии исходников/инструментов |
