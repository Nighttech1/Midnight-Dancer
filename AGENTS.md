# Midnight Dancer — общий контекст команды

Перед работой над продуктом прочитай:

1. [Индекс исходных данных](project-context/README.md).
2. [Продуктовый бриф основателя](project-context/PRODUCT_BRIEF.md).

Используй эти документы как исходный продуктовый контекст. Отличай описание основателя от проверенной реализации и гипотез команды. Не выдавай наличие функции в брифе за доказательство её готовности в коде.

Новые продуктовые решения фиксируй с датой и источником. Не подменяй неизвестные данные предположениями и не переноси вводные других проектов без основания.

## Команда продукта

Для нового чата директора продукта начать с [team/START-DIRECTOR.md](team/START-DIRECTOR.md) и пройти указанное обязательное чтение. Должности, подчинение и методики — [team/registry.json](team/registry.json); полномочия — [team/CONSTITUTION.md](team/CONSTITUTION.md); вызов субагентов — [team/ORCHESTRATION.md](team/ORCHESTRATION.md).

Владелец разрешил подключать субагентов по необходимости. Не выдавать последовательное исполнение ролей за независимую командную проверку. Все документы проекта сохранять здесь; публичный репозиторий не должен содержать ключи, персональные данные и закрытые выгрузки. Внешние сообщения, публикации, платные API и production-деплой требуют явного разрешения владельца.
